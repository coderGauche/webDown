# SiteCapsule 使用说明

> 适用版本：0.1.0 工程试用版
> 当前状态：仅供受限工程试用，尚未达到 MVP 发布门槛。

SiteCapsule 将当前 Chrome 标签页的最终 DOM 和已发现资源打包为 ZIP，用于离线查看、
研究和备份。当前版本只归档当前页面，不会递归下载整个网站。

## 创建归档

1. 在 Chrome 中打开有权保存的公开 HTTP 或 HTTPS 页面，等待页面主要内容出现。
2. 点击 SiteCapsule 扩展图标打开侧边栏。
3. 选择中文或 English，然后点击“使用当前页面”或“刷新页面”。
4. Chrome 请求当前站点权限时确认授权。SiteCapsule 读取页面标题、最终 DOM 和资源线索。
5. 检查 ZIP 文件名并设置捕获选项：
   - 渲染等待：0-30,000 毫秒；动态页面可适当增加。
   - 并发下载数：1-12，默认 6。
   - 离线动画与交互：默认关闭。开启后，已归档脚本会在禁止外联的 CSP 沙箱中运行；
     模块依赖表和脚本内嵌的静态图像/帧资源会继续发现并归档；依赖原站路由或 API 的页面仍可能降级。
   - 媒体文件：默认关闭；开启后可能显著增加内存和下载时间。
   - 归档关键第三方资源：默认开启。CSS、图片、字体、脚本等关键主机默认勾选，点击
     “授权所选项”后 Chrome 只申请界面列出的精确主机；追踪、支付和 iframe 等运行时
     主机默认排除。
6. 点击“创建归档”。任务进行时可暂停、继续或取消；失败任务可按界面提示重试。
7. 出现“归档已就绪”后点击“下载 ZIP”。请在关闭或重载扩展前完成下载。

第三方主机授权不是整站永久抓取指令。扩展只对当前任务发现的归档关键来源申请精确
主机访问。关键主机尚未授权时不能创建普通任务；主动关闭“归档关键第三方资源”后可以
继续，但界面会明确提示归档可能不完整。

读取页面时，SiteCapsule 只清理用于归档的 DOM 克隆：删除其他浏览器扩展注入的资源节点、
明确的追踪或支付运行时，以及不能独立离线工作的普通 iframe；自包含 `srcdoc` iframe 会保留。
“捕获诊断”会按原因显示移除计数。原标签页不会被修改。

开启实验性离线交互模式后，会运行已存入 ZIP 的脚本和页面内联脚本，并改写已保存的静态
`import`、Worker、WASM/资产 URL 和 `fetch` 引用。归档 CSP 只允许同源本地资源，禁止外部脚本、
远程连接、表单提交和 Service Worker 注册。默认关闭该开关时，可执行脚本会被冻结，
归档仅保留捕获时的最终 DOM。无法保存的资源引用会被移除或中和，并在失败清单中记录。

## 离线查看

1. 将 ZIP 解压到普通本地目录。
2. 简单静态页可先尝试直接打开 `index.html`。
3. ES Module、绝对路径、浏览器安全策略或 `file://` 限制可能导致直接打开失败。更可靠的
   方式是在解压目录启动只监听本机的 HTTP 服务：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

4. 在浏览器访问 `http://127.0.0.1:8000/`。使用完毕后在终端按 `Ctrl+C` 停止服务。

不要把解压目录放到公网 Web 服务器，除非你拥有发布其中全部内容的权利并已完成安全
检查。ZIP 可能包含原网站脚本文件；虽然离线入口默认禁用执行，归档内容仍不应被视为可信代码。

## 本地任务

- 任务状态和资源元数据保存在浏览器本地存储中，可在“本地任务”查看和清理。
- ZIP 二进制只保留在当前扩展运行会话。Service Worker 重启、扩展重载或浏览器状态变化后，
  历史任务可能显示“仅元数据”，此时必须重新执行归档才能再次下载。
- “清空历史”会删除终态任务的本地记录；活动任务会保留。

## 排错

- “当前页面不允许注入内容脚本”：切换到普通 HTTP/HTTPS 页面。`chrome://`、Chrome
  Web Store、扩展页和部分受保护页面不能捕获。
- “捕获期间页面发生了跳转”：等待页面稳定后重新读取并创建新任务。
- 第三方资源缺失：开启归档关键第三方资源，授权默认选中的必要主机后重试。
- 页面很大或任务长时间下载：关闭媒体、减少第三方资源或降低并发后重试。
- 双击后空白或路径错误：使用上面的本地 HTTP 服务；若仍失败，请查看已知限制。

详细边界见[已知限制](./known-limitations.md)，数据处理见[隐私说明](./privacy.md)。
